# Assets

Every external asset shipped with the game, with source, URL, and license. This file is generated by `npm run assets` from `scripts/assets/catalog.mjs` and the metadata returned by each source API at download time. The license of each source was confirmed from that source's own license page during the run (see the evidence column).

Raw downloads live in `asset-src/` and processed files in `public/assets/`. Both are ignored by git and rebuilt by the pipeline. The manifest `src/render/assets.manifest.json` is committed.

No asset contains a real person's likeness or name, and nothing comes from a commercial game.

Shipped size: **41.89 MB** (textures 19.06 MB, models 12.53 MB, HDRIs 10.30 MB).

## License evidence

- ambientcg: CC0 1.0. License page states assets are licensed under Creative Commons CC0 1.0. Source: https://docs.ambientcg.com/license/
- polyhaven: CC0 1.0. License page states all assets are CC0 (public domain). Source: https://polyhaven.com/license
- Poly Haven API terms (https://github.com/Poly-Haven/Public-API/blob/master/ToS.md): the API is free for any use; requests carry the user agent `fairway-next-asset-pipeline`. The API is used at build time only, never from the running game.

The old project's four baked HDRIs and its Mixamo golfer were not available in the build environment and are not used.
